# UI Components

This directory contains the updated UI components with white background and black text styling.

## Components

- **ContainerScreen.js** - Main container component with updated color scheme
- **Container.js** - Header container component
- **ContainerWrapper.js** - Left panel with camera controls
- **Div.js** - System status panel
- **DivWrapper.js** - Live feeds grid panel

## Image Assets

The following image files are referenced but need to be provided:
- group-2.png
- group-3.png  
- group-4.png
- group-5.png
- image.png

## Color Scheme

All components now use:
- White backgrounds (#FFFFFF)
- Black text (#000000)
- Gray borders and accents
- Consistent with the updated VMS theme

## Usage

```jsx
import { ContainerScreen } from './components/ui/ContainerScreen';

function App() {
  return <ContainerScreen />;
}
```
